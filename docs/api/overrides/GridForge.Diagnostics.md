The diagnostics namespace projects active worlds into engine-neutral cell,
geometry, query-status, and dirty-change descriptors. It does not render or own
engine state.

The [GridForge-Unity adapter](https://mrdav30.github.io/GridForge-Unity/) uses
these contracts for scene gizmos and topology-aware visualization.
